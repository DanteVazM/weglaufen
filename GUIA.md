----COMO SUBIR A LA MAIN (CUIDADITO! ES LA MAIN BRANCH) LO QUE TRABAJASTE---- 
Para subir en la main branch (CUIDADO) corres este comando en GitBash:
git add . ; git commit -m "pone comentario x e los cambios"; git push

----COMO CREAR UNA NUEVA BRANCH---- 
Para crear una nueva branch, se corre el siguiente comando:
git checkout -b desarrollo-equipo
ADVERTENCIA, ESTO TE CAMBIA AUTOMATICAMENTE AL NUEVO BRANCH
(Para pushearlo por pirmera vez usas: git push --set-upstream origin alfa1)
